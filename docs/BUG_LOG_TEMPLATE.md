# Experience Caddie – Bug Log Template

Copy the block below into a doc (Google Doc, Notion, etc.) and duplicate the row for each bug you find. Fill in the columns as you test.

---

## How to use

1. Copy the **table** (or the row template) into your document.
2. For each issue: add one row, fill every column.
3. **What you did** = exact steps (e.g. “Clicked Find Tickets on Santana in Silver tier”).
4. **What you expected** = what should have happened in plain English.
5. **What actually happened** = what you saw (message, blank page, wrong link, etc.).
6. **Where it happened** = URL or screen name (e.g. “Itinerary results page, Silver tab”).
7. **Severity** = pick one: **Blocker** (can’t complete main flow), **Major** (big problem, workaround exists), **Minor** (small or rare), **Cosmetic** (looks wrong, works fine).
8. **Extra info** = optional: browser, device, logged in or not, screenshot filename.

## Severity guide (plain English)

- **Blocker:** I couldn’t finish the main task (e.g. never got an itinerary, or could never open tickets).
- **Major:** Something important is wrong (e.g. wrong link, wrong data, or track-click always fails), but I could still use the app with a workaround.
- **Minor:** Small bug or rare case (e.g. one button mislabeled, or issue only in one city).
- **Cosmetic:** Layout or wording is off but behavior is correct.
